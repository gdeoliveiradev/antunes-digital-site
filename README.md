# Antunes Digital — Corporate Website

> Tecnologia prática para negócios · Practical technology for business

Site institucional da **Antunes Digital**, uma iniciativa pessoal voltada à criação de sites, automações e sistemas digitais para resolver problemas reais de pequenos negócios.

**English summary:** A modern and responsive corporate website for Antunes Digital, focused on practical digital solutions, business discovery and an adaptive client pre-diagnosis experience.

## Status

`MVP / Active development` — primeira versão funcional, responsiva e em evolução contínua.

## Sobre o projeto · About

O projeto nasceu para posicionar a Antunes Digital como uma empresa de soluções digitais, sem limitar a marca ao modelo tradicional de agência de marketing.

O site apresenta:

- proposta de valor e posicionamento;
- serviços de `Web Development`, `Automation` e `Custom Software`;
- processo de descoberta e desenvolvimento;
- princípios da empresa;
- conceito **Antunes Lab** para futuros produtos e experimentos;
- formulário de pré-diagnóstico com resposta adaptada ao problema informado;
- experiência responsiva para desktop e dispositivos móveis.

## Diferencial técnico · Key feature

O diagnóstico inicial analisa palavras e contexto do problema relatado e direciona o visitante para um caminho coerente, como:

- site e experiência digital;
- organização comercial;
- automação de processos;
- agendamento e atendimento;
- sistema de controle operacional.

Essa análise é uma orientação inicial, não uma decisão automática sobre o projeto.
